# Конструктор управленческих презентаций

Приложение помогает создавать презентации PowerPoint по финансовым данным. Вы выбираете источник данных, добавляете нужные слайды, настраиваете диаграммы и скачиваете готовый файл PPTX. Диаграммы можно редактировать в PowerPoint.

## Возможности

- Загрузка финансовых данных из CSV, XLSX или SQL-файла.
- Получение информации из базы данных по SQL-запросу.
- Создание презентации из нескольких слайдов: одна диаграмма на одном слайде.
- Выбор вида анализа: **план-факт**, **динамика показателей** или **структура расходов**.
- Настройка периода, показателя, заголовка и доступного типа диаграммы.
- Дублирование, удаление и изменение порядка слайдов.
- Добавление титульного слайда и выбор стиля оформления презентации.

## Как запустить приложение

Для запуска понадобятся **Python 3.12** и **Node.js (версия LTS)**. Установите их заранее, если они отсутствуют:

- Python: https://www.python.org/downloads/
- Node.js: https://nodejs.org/

Распакуйте архив проекта. Для работы приложения нужно запустить две части: сервер (`backend`) и интерфейс (`frontend`). Они работают одновременно, в двух окнах терминала.

### Windows

**1. Запустите сервер.** Откройте PowerShell в папке `backend` и выполните команды по очереди:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

**2. Запустите интерфейс.** Откройте второе окно PowerShell в папке `frontend`:

```powershell
npm install
npm run dev
```

**3.** Откройте в браузере http://localhost:5173/.

При следующем запуске повторять создание окружения и установку зависимостей не требуется. В `backend` достаточно выполнить:

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

`frontend`:

```powershell
npm run dev
```

## Как создать презентацию

1. **Выберите источник данных.** Загрузите файл CSV, XLSX или SQL. Если данные находятся в базе, выберите вкладку SQL и укажите параметры подключения и запрос.
2. **Настройте презентацию.** Введите название, выберите стиль оформления и при необходимости добавьте титульный слайд.
3. **Добавьте слайды.** Нажмите «Добавить слайд с диаграммой» и укажите вид анализа, показатель и отчетный период. Для анализа динамики задайте диапазон месяцев.
4. **Настройте порядок.** Перемещайте слайды стрелками. Чтобы создать похожую диаграмму за другой месяц, продублируйте слайд и измените период.
5. **Скачайте результат.** Нажмите «Сформировать и скачать PPTX».

## Какие данные нужны

Для большинства диаграмм файл должен содержать следующие столбцы:

| period | category | plan | fact |
|---|---|---:|---:|
| 2026-10 | Выручка | 1200000 | 1270000 |
| 2026-10 | Расходы | 800000 | 830000 |

- `period` — месяц в формате `ГГГГ-ММ`.
- `category` — название финансового показателя.
- `plan` — плановое значение.
- `fact` — фактическое значение.

Для **структуры расходов** добавьте столбец `kind` со значением `expense` у строк, относящихся к расходам. Для **анализа динамики** нужны данные за несколько месяцев.

Примеры файлов находятся в папке `samples`. Для начала удобно использовать `finance_reports.csv`.

**SQL-файл** можно загрузить без подключения к базе данных, если он содержит таблицу и готовые записи в формате `CREATE TABLE` и `INSERT INTO`. Пример: `samples/finance_reports.sql`.

Максимальный размер загружаемого файла — **100 МБ**.

## Если приложение не запускается

- **Команда `python` не найдена** — на macOS/Linux активируйте окружение через `source .venv/bin/activate`. На Windows используйте указанный выше путь `.\.venv\Scripts\python.exe`.
- **Команда `npm` не найдена** — установите Node.js с сайта [nodejs.org](https://nodejs.org/) и заново откройте терминал.
- **Ошибка HTTP 500 или ошибка соединения** — проверьте первое окно Терминала: сервер FastAPI должен быть запущен без ошибок.
- **Презентация не создается** — проверьте названия столбцов, выбранный период и наличие данных для нужного показателя.

Приложение работает локально на вашем компьютере. Для обычной работы не требуется размещать файлы на внешнем сервере.
